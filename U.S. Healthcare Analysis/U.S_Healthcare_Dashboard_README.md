## 📌 Overview

This Power BI project provides an in-depth analysis of the U.S. healthcare system from 2019 to 2020, offering stakeholders and decision-makers actionable insights into hospitals, patients, providers, and financial trends.

The dashboard is structured as a storytelling tool with focused chapters, empowering users to navigate complex healthcare data efficiently and make informed decisions.

---

## 🔍 Key Features

### 🏥 Hospital Analysis
- Evaluation of performance metrics across 11 hospitals
- Monitoring ARGE (Accounts Receivable Gross Efficiency) and IPTP (In-Patient Throughput Performance) ratios
- Distribution of CPT (Current Procedural Terminology) units
- Key financial metrics like gross expenses and accounts receivable

### 👨‍⚕️ Patient Insights
- Demographic breakdown (gender, blood group, lifestyle habits)
- State and region-based patient distribution
- Trends in patient engagement and outcomes

### 💰 Payer-Provider Relationships
- Analysis of payment streams from Medicare, Medicaid, commercial payers, etc.
- CPT unit distribution by payer
- Revenue generation and procedure volume across time

### 📈 Financial Trends
- Monthly expenses overview with gross and adjusted expenditure
- Payment trends and insurance contributions
- Optimization indicators for financial planning

---

## 📂 Data & Tools

- **Tool Used**: Power BI (Uploaded from Power BI Desktop)
- **Data Source**: Healthcare datasets (stored locally)
- **Time Period Covered**: 2019–2020
- **Scope**: National-level healthcare metrics, segmented by hospital, state, and region
